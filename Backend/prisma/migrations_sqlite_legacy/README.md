# Migrations SQLite legadas (arquivadas)

Estas migrations foram geradas para SQLite (`DATETIME`, `PRAGMA`) e **não podem
ser executadas no PostgreSQL**. Foram movidas para cá, sem alteração, para
preservar o histórico. O diretório ativo `prisma/migrations/` agora contém o
baseline PostgreSQL (`0_baseline`) e as migrations posteriores.

Nunca execute estes arquivos no Neon.
